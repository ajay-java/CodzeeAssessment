# CodzeeAssessment
This repository is used to complete the Codzee Assessment

## Database Configuration

The application requires Oracle and MySQL database credentials to be
configured through environment variables.

Required environment variables:

- `ORACLE_DB_USERNAME`
- `ORACLE_DB_PASSWORD`
- `MYSQL_DB_USERNAME`
- `MYSQL_DB_PASSWORD`

Configure these variables in your local environment before starting
the application. Do not commit database credentials to source control.
